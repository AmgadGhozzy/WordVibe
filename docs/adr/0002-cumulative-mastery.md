# Cumulative mastery with always-demote

Mastery counts lifetime cumulative successes (recall≥3, production≥3, stability≥2.0); any real failure demotes to KNOWN without erasing counters. We rejected last-N windows (window state per word, no pilot evidence for it) and failure thresholds (non-deterministic leniency). Historical evidence and current mastery state are separate concepts: failure changes state, never history.
